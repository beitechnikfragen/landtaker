# Contributing

**Landtaker is not currently accepting external contributions.** Pull
requests and issues opened here will be closed unread — not out of
rudeness, but because this is a small project run by one person and
reviewing outside code is work we cannot commit to right now.

## Found a bug? Have an idea?

Use the **feedback button in the game** (bottom-left corner, in the menu
and during a match). It reaches us directly and carries the context we
need — which match you were in, which build you were running.

For anything else: [Discord](https://discord.gg/FztuCAcVGD) ·
[r/landtaker](https://www.reddit.com/r/landtaker/)

## Why the source is public

The code is [AGPL-3.0](LICENSE). Running a modified version as a network
service obliges us to publish that version's source, and this repository
is how we meet that obligation. Open source means you may read, fork and
run it — it does not mean this repository takes patches.

If you want to build on it, fork it. That is what the licence is for, and
it is exactly what Landtaker itself did with
[OpenFront.io](https://github.com/openfrontio/OpenFrontIO).

Note that `/brand` (the Landtaker marks, rank insignia and fonts) is **not**
covered by the code licence — see [brand/LICENSE](brand/LICENSE). A fork
needs its own identity.

## If this changes

We may open up later. When that happens, this file changes first.
